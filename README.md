# MUUMEI 公開配布

招待制プライベートSNS「MUUMEI」の静的配布物です。

- [MUUMEI](https://mumei-s.github.io/muumei-public/)
- [参加者の操作サンプル](https://mumei-s.github.io/muumei-public/review/)

紹介ページ・実会員画面・参加者サンプルを、同じ正本からコンパイルしています。0.25では、柄付きの写真背景、整理した会員ホーム、横長のプライベートカード、ホーム追加アイコンを刷新しました。キラキラ・流れる光・紹介動画を、常設の「演出 ON/OFF」でまとめて切り替えられます。設定は端末に保存され、端末の明暗表示と動きを減らす設定にも対応しています。

チャットは最新のメッセージから読み始められ、過去の会話を読んでいる間の位置を保ちます。

一般登録の受付は停止中です。サンプルは架空データだけで動き、本番の登録・投稿・送信を行いません。実会員の認証画面とサンプルの入口は分離しています。

OWNER管理画面は、この公開配布に含みません。認証付き管理画面と招待QRの配布物は、独立した公開先のために別途準備しています。実認証・招待・通知の運用開始には、専用の設定と通し確認が必要です。

`docs/` はコンパイル済み配布物のみです。配布元の版は `release-receipt.json` で確認できます。正本ソースは非公開リポジトリで管理しています。

配布元ソース: `4e14618f614ce2ac5450e481c56e98a02859adf6`

データベースや認証サービスの設定は、このリポジトリの公開によって変更されません。
