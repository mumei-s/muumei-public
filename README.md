# MUUMEI 配信専用リポジトリ

正本ソースは別のPrivateリポジトリで管理します。このmainにはアプリの元コード、環境ファイル、DB定義、サーバー秘密鍵を置きません。

## 復旧状況

- 誤って配置した `apps/` と `scripts/` を現行mainから除去しました。
- 過去コミットの履歴には、以前コピーしたフロントエンドの元コードが残っています。この変更は履歴の完全消去ではありません。
- GitHub Pages用の配信ファイルと検証を準備中です。公開・本番稼働済みとは扱いません。
- 既存のOWNER権限、Supabaseのデータ・RLS、INSIGHTは変更しません。

公開時はビルド済みファイルのみを `docs/` に配置します。
