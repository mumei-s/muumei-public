# MUUMEI 公開配布

招待制プライベートSNS「MUUMEI」のコンパイル済み配布物です。

- [MUUMEI](https://mumei-s.github.io/muumei-public/)
- [参加者の操作サンプル](https://mumei-s.github.io/muumei-public/review/)

白い大理石の実写写真に、静的な反射光・反射の暗部・縁のハイライトを重ね、磨いた素材の質感を付けています。反射はUI上で描画する表現です。パール・紺・チェリー系の配色を使用しています。スマートフォンでの見出しと説明文の比率、狭い幅での左右余白、ログインボタンの中央揃え、参加ボタンと紹介動画の大きさを整えました。入口のアイコンにはローズ・ミント・ゴールドの差し色を用いています。

端末のライト／ダーク表示に対応し、キラキラ・流れる光・紹介動画は常設の演出ON/OFFで切り替えられます。設定は端末に保存され、動きを減らす設定にも対応しています。

一般紹介・実会員の認証画面・架空データの参加者サンプルは分離しています。一般登録の受付は停止中です。サンプルから本番の登録・投稿・送信は行いません。

OWNER管理画面はこの公開配布には含みません。独立した公開先と認証設定、実際の招待・承認・DM・端末通知の通し確認は別途必要です。

正本ソースは非公開リポジトリで管理しています。今回の配布元コードは `072077fd533b71f7f23586319da3b39e2c666d6f`。詳細は `docs/release-receipt.json` で確認できます。この配布によってデータベース・認証・通知・課金設定は変更されません。
